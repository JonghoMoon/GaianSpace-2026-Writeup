# Maintenance manual, one surviving fragment

The station log is not the mailbox and it is not an internet packet. It is the relay’s own notebook, carried the same way the other private letters were carried, under a type the manual calls “ours.”

The capture does not begin on a boundary. The person who started the recorder was late. Searching from the first byte as if it were a fresh page will invent a frame that is not there. A real page introduces itself, and that introduction carries a small check. Trust the check, not the start of the file.

Inside a page the notebook is a sequence of short records. Each record is a kind, a length, and then that many bytes.

One kind of record is the banner. It was written clean, on purpose, so a tired engineer could read the version and the ink without a tool. Every other record was dragged through that same ink. One mark, used again and again, not a new cipher each line.

Pell tried a letter-shift because he always tries a letter-shift. The banner is not a riddle. It names the ink in ordinary words.

When the ink lifts, the line the bridge asked for is the one the station itself labeled as the thing to keep.
